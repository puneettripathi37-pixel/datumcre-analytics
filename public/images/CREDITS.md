## Founder portrait

`founder-puneet-tripathi.jpg` is a photograph of Puneet Tripathi supplied by
the founder for use on this site. It is cropped to 4:5 (960×1200) and is not a
stock image. The portrait is enabled via `imageEnabled` in
`src/lib/founder.ts`; set it to `false` to fall back to the monogram panel.

To replace an image, drop a new file into `public/images/` using the same
filename (or update the path in the relevant data file). Recommended formats:
JPEG or WebP, 1200–2000 px on the long edge.
